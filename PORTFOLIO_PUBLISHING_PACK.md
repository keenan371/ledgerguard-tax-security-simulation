# LedgerGuard Portfolio Publishing Pack

## LinkedIn project

### Title

LedgerGuard - IAM and Security Readiness Simulation for a Tax Firm

### Description

I built a fictional seven-person accounting-firm environment to demonstrate an evidence-based security engagement from scope through verification. The project covers identity and access inventory, MFA, least privilege, administrative access, endpoints, backups, logging, incident procedures, risk prioritization and an owner-ready remediation roadmap.

Every artifact uses synthetic evidence. The project does not claim a real client, production tenant or compliance certification. Its purpose is to show how I translate business risk into bounded controls, define acceptance tests and preserve a clear evidence trail.

Repository: https://github.com/keenan371/ledgerguard-tax-security-simulation
